Política de privacidad

Última actualización: 21 de noviembre de 2026

Esta política explica qué datos guarda Tata (el "bot"), el bot de Discord de mitología latinoamericana, para qué los usa y cómo podés pedir que se borren. Al agregar el bot a un servidor o usar sus comandos, aceptás esta política.

Qué datos guardamos

  • Identificadores de Discord: el ID de tu usuario y el ID del servidor donde jugás. No guardamos tu correo, tu contraseña ni tus mensajes.
  • Progreso del juego (por servidor): nivel, XP, don, pesos, huayruros, reliquias, nahuales, materiales, pactos, títulos, cosméticos (por ejemplo, el apodo que le pongas a tu nahual), récords y tiempos de espera.
  • Configuración del servidor: canales, roles, prefijo, idioma y mensajes de bienvenida que elijan los administradores con /config.
  • Moderación: si un moderador usa /warn, se guarda la advertencia con el ID del usuario, el ID del moderador, el motivo escrito y la fecha.
  • Votos: cuando votás en páginas de bots (como Discord Bot List o Top.gg), esas páginas nos informan tu ID de usuario y el momento del voto, para darte la recompensa.
  • Premium: si apoyás al bot, guardamos tu ID (o el del servidor), el tipo de premium y hasta cuándo dura. Los pagos los procesan Ko-fi, Mercado Pago o Cafecito: nosotros no vemos ni guardamos datos de tarjetas.

Contenido de los mensajes

El bot lee los mensajes de los canales donde tiene acceso solo para detectar comandos con prefijo (por ejemplo ?perfil), las respuestas de los eventos del chat y si hay actividad para hacer aparecer criaturas. No guarda el contenido de los mensajes, salvo lo que vos mismo escribís como parte de un comando que se guarda (un motivo de advertencia, un mensaje de bienvenida, un apodo).

Para qué los usamos

Solo para que el bot funcione: mostrar tu perfil y rankings del servidor, aplicar la configuración y la moderación, dar recompensas y activar el premium. No vendemos ni compartimos tus datos con nadie, ni los usamos para publicidad.

Dónde se guardan y por cuánto tiempo

Se guardan en el servidor donde corre el bot. Se conservan mientras el bot siga activo, para que no pierdas tu progreso. Las advertencias pueden vencer solas si el servidor lo configura. Podés pedir que se borren en cualquier momento (ver abajo).

Tus derechos

Podés pedir ver, corregir o borrar tus datos (o los de tu servidor, si sos administrador). Escribinos por el canal de contacto y lo hacemos en un plazo razonable. Borrar los datos del juego significa perder el progreso, y no se puede deshacer.

Menores

El bot sigue las reglas de Discord, que exigen una edad mínima para usar la plataforma. No buscamos recolectar datos de menores de esa edad.

Cambios

Si cambiamos esta política, actualizamos esta página y la fecha de arriba.

Contacto

Para cualquier consulta o pedido sobre tus datos: servidor de soporte · formulario de contacto.

Privacy policy

Last updated: November 21, 2026

This policy explains what data Tata (the "bot"), the Latin American folklore Discord bot, stores, what it uses it for and how you can ask for it to be deleted. By adding the bot to a server or using its commands, you agree to this policy.

What data we store

  • Discord identifiers: your user ID and the ID of the server where you play. We don't store your email, your password or your messages.
  • Game progress (per server): level, XP, gift, pesos, huayruros, relics, nahuales, materials, pacts, titles, cosmetics (for example, the nickname you give your nahual), records and cooldowns.
  • Server settings: channels, roles, prefix, language and welcome messages chosen by admins with /config.
  • Moderation: when a moderator uses /warn, the warning is stored with the user's ID, the moderator's ID, the written reason and the date.
  • Votes: when you vote on bot list sites (such as Discord Bot List or Top.gg), those sites tell us your user ID and the time of the vote, so we can give you the reward.
  • Premium: if you support the bot, we store your ID (or the server's), the premium type and when it ends. Payments are handled by Ko-fi, Mercado Pago or Cafecito: we never see or store card details.

Message content

The bot reads messages in channels it can access only to detect prefix commands (such as ?profile), answers to chat events and whether there's activity to spawn creatures. It doesn't store message content, except what you write yourself as part of a command that gets saved (a warning reason, a welcome message, a nickname).

What we use it for

Only to make the bot work: showing your profile and server leaderboards, applying settings and moderation, giving rewards and activating premium. We don't sell or share your data with anyone, and we don't use it for advertising.

Where it's stored and for how long

It's stored on the server where the bot runs. It's kept while the bot is active, so you don't lose your progress. Warnings can expire automatically if the server sets that up. You can ask for deletion at any time (see below).

Your rights

You can ask to see, correct or delete your data (or your server's, if you're an admin). Write to us through the contact channel and we'll do it within a reasonable time. Deleting game data means losing your progress, and it can't be undone.

Children

The bot follows Discord's rules, which require a minimum age to use the platform. We don't knowingly collect data from people under that age.

Changes

If we change this policy, we'll update this page and the date above.

Contact

For any question or request about your data: support server · contact form.
